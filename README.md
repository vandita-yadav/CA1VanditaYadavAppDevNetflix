# 📱 Netflix Login UI – Android App (Kotlin + XML)

A simple and clean Netflix-style login screen built using **Kotlin** and **XML** with a **LinearLayout**-based design.  
This project demonstrates basic UI layouting, resource handling, drawable usage, and simple button click functionality.

---


## 🎯 Features

- Netflix-inspired login screen  
- LinearLayout-based structure  
- Logo on top, Sign-in title, input fields, QR image  
- Email/Phone and Password fields  
- Sign-in button with onClick text output  
- “Remember me”, “Need help?”, “Login with Facebook” sections  
- QR code image beside Sign-In button  
- Lightweight & beginner-friendly UI project
